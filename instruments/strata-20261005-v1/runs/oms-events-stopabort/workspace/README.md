Repair solution.py: replay(events) processes a list of dictionaries in input order. Every dictionary has exactly keys account, action, amount. account is a nonempty string with no leading/trailing whitespace. action is open, deposit, withdraw, or close. amount must be an int excluding bool. open and close require amount == 0; deposit and withdraw require amount > 0. An account must be opened exactly once before any other action; open creates balance zero. Withdrawal cannot exceed its balance. close requires zero balance; any action after close, including open, is invalid. Return tuples (account, balance, status), sorted by account; status is open or closed. Retain closed accounts. Empty input returns []. Invalid record shape, fields, or transition raises ValueError. Do not mutate input even when raising. The outer input is always a list. Python 3.11, standard library only.
