Repair solution.py: normalize(entries) accepts a list of relative POSIX file-path strings and returns unique normalized paths sorted lexicographically. A path must be a nonempty string, cannot start with /, and cannot contain backslash or a NUL character. Split on /; ignore empty and . components; .. pops one preceding component and is invalid if no component is available at that point. Reject paths that normalize to empty. Other components are literal, case-sensitive names, including spaces and colons; no filesystem access or URL decoding. Duplicate normalized paths collapse. Reject a manifest if one normalized file path is an ancestor of another (for example a and a/b); a and ab do not conflict. All invalid paths, invalid element types, and file/descendant conflicts raise ValueError. The outer input is always a list. Do not mutate it, including on errors. Empty input returns []. Python 3.11, standard library only.
