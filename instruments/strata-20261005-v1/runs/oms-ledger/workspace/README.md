Repair solution.py: reconcile(text) reads CSV from a string and returns sorted (account, balance, transaction_count) tuples, ordered by account. Header must be exactly account,kind,cents in that order. Each subsequent CSV record must have exactly three fields. account is a nonempty string with no leading/trailing whitespace; internal whitespace and commas are allowed. kind is exactly credit or debit. cents is one or more ASCII digits, with optional leading zeros, representing a nonnegative integer. credit adds cents, debit subtracts it; negative balances are allowed. Include accounts with zero balance and count zero-value transactions. Empty text, malformed CSV quoting under csv.reader(strict=True), wrong header, blank records, wrong field counts, or invalid fields raise ValueError. A header alone returns []. Do not strip or reinterpret field contents. Input is always a string. Python 3.11, standard library only.
